# Phase 2 and 3 — Growth and Scale (combined copy)

All copy for the pages that follow the launch, in one folder. Files starting `p2-` are Phase 2 (growth). Files starting `p3-` are Phase 3 (scale). `00-` files apply to both.

## Rules
1. **Do not publish a page until its "Publish when" condition is true.** Every file states it at the top. Hidden pages must stay out of navigation and `sitemap.xml` (see `03-SITEMAP-AND-ROUTES.md`).
2. **Honest copy.** Pages describe what KOINOVA is designed to offer. Update the wording as programmes become real. Never add numbers, partners, testimonials or alumni that do not exist yet.
3. **Placeholders** in `[CAPITALS]` need your real details. Common ones: `[CONTACT EMAIL]`, `[MENTORSHIP EMAIL]`, `[FELLOWSHIPS EMAIL]`, `[DONATION LINK]`, `[FEE]`, `[DATE]`, `[REGISTERED ENTITY NAME AND COUNTRY]`.
4. Styling, images and animation follow the build specs, not these files.
