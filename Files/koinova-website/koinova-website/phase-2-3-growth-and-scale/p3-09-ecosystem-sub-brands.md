# Ecosystem sub-brands

The five components stay one family: shared logo system, type, tokens and components. Each has a name, tagline and accent family so it can be recognised on its own.

| Component | Name | Tagline | Gradient family (see `05-DESIGN-SYSTEM.md`) |
|---|---|---|---|
| Community | KOINOVA Community | Connect. Collaborate. Grow. | Blue |
| Academy | KOINOVA Academy | Learn. Build. Lead. | Blue |
| Innovation | KOINOVA Innovation | Imagine. Experiment. Solve. | Emerald |
| Ventures | KOINOVA Ventures | Build. Grow. Create value. | Emerald |
| Global | KOINOVA Global | Connected across borders. | Blue |

## Naming rules
- Always "KOINOVA" first, then the component name in the same type style (for example "KOINOVA Academy").
- Never abbreviate the component name or drop "KOINOVA" in headings and logos.
- Programmes use plain descriptive names (for example "Founder Mentorship") rather than invented brand names.

## Visual rules
- Each component uses one gradient family only, as in the design system.
- Each has an icon from the same line set (network, book, spark, rocket, globe).
- Layouts, spacing, buttons and animation stay identical across components.
- The gold JOIN KOINOVA button stays consistent everywhere.

## Logo lockup
`[KOINOVA LOGO] | Component name`, with the component name in the body font at medium weight, separated by a thin vertical rule. Provide light and dark versions. Do not create separate component logos until the client supplies them.

## Section structure
Each component's section can include a landing page, programmes, resources, news and events, plus a "Join" call to action.
